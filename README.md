# IMDB Sentiment Analysis (LSTM)

Классификация тональности отзывов о фильмах с помощью LSTM.

## О проекте

Модель определяет, является ли отзыв **positive** или **negative**.
Используется датасет IMDB (50 000 отзывов).

## Технологии

- Python 3.x
- PyTorch
- Pandas
- NumPy
- Scikit-learn

## Архитектура модели:

Embedding → LSTM → Dropout → Linear → Sigmoid
